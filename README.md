# Ranjan Kumar Shaw — 3D Cinematic Developer Portfolio

A modern, immersive, interactive 3D developer portfolio built with **Three.js**, **Vanilla JavaScript**, and **Vite**.

## 🚀 Live Features
- **Cinematic 3D Workspace**: Fully procedural 3D developer environment featuring an ultrawide curved monitor, mechanical keyboard, precision mouse, laptop, studio speakers, ergonomic chair, and animated developer character.
- **Dynamic 3D Cursor Physics**: Moving the cursor dynamically moves, tilts (yaw & pitch), and tracks the desk, character head, and lighting in real-time 3D space.
- **Dark Mode Cyber Aesthetic**: Matte surfaces, clean dark atmosphere (`#060913`), subtle bloom post-processing, and no harsh light glare.
- **Modular HUD & Project Showcase**: Quick access drawer modals for About, Skills, Projects, Experience, Research, Certifications, and Contact.
- **Synthesized Web Audio Engine**: Interactive sci-fi audio feedback generated natively via Web Audio API without external audio files.

## 🛠️ Tech Stack
- **Three.js** (WebGL 3D Rendering & Shaders)
- **Vite** (Build Tool & Dev Server)
- **Vanilla CSS3** (Modern responsive UI & glassmorphism)
- **Web Audio API** (Interactive SFX)

## 💻 Local Setup & Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/heyranjanshaw07/<your-repo-name>.git
   cd <your-repo-name>
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local dev server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
